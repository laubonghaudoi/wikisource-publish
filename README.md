# wikisource-publish

A Codex skill for publishing proofread Markdown and its source PDF, images, and tables as a single full-text page on Chinese Wikisource.

## Install

Copy this repository into your Codex skills directory as `wikisource-publish`, then start a new Codex session. See [SKILL.md](SKILL.md) for the workflow and credential setup.

The skill preserves source Markdown, PDFs, and images. It does not perform OCR or rewrite the text.
